# Signum translation file -> altea translation file, for translation-convert.

# Paths are bases WITHOUT the `.<culture>.xml` suffix, and resolve against the roots below, which in turn
# resolve against this file's own directory.
#
# ONE SOURCE, ONE TARGET. A Signum assembly becomes exactly one altea package, and a type is translated in
# the assembly that DECLARES it: `ActiveDirectoryMessage` lives in Signum.Authorization.BaseAD.ts, so its
# strings come from Signum.Authorization, not from the stale copy in Signum.Authorization.WindowsAD. Where
# altea split one Signum type in two, translationRenames.txt duplicates the snippet inside that one target.
#
# A pair whose source file does not exist is skipped, so every culture can be listed once here.
